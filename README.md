# Bright_Coffee_Shop_Sales_Analysis
This project analyzes the daily transactional information captured by Bright Coffee shop. The mission of the coffee shop is to grow the company's revenue and improve product performance by extracting insights from its historical data. It makes use of analytics, SQL, and data visualization skills to help Bright Coffee shop's CEO in decision-making.
